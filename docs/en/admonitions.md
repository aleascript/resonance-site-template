# Admonitions

This page is a living visual reference for the Markdown admonitions supported by
the template. It is intentionally included in both the website and the sample
publication so that every renderer exercises the same source syntax.

:::note[Note]
Use a note for useful context that deserves attention without changing the
reader's course of action.
:::

:::tip[Tip]
Use a tip for a practical suggestion, shortcut, or technique that can make play
or preparation smoother.
:::

:::info[Information]
Use information when a fact, definition, or clarification should stand apart
from the surrounding text.
:::

:::warning[Warning]
Use a warning when the reader should proceed carefully because a choice may have
important consequences.
:::

:::danger[Danger]
Use danger for the strongest caution: something likely to break, invalidate, or
seriously disrupt the intended result.
:::

:::design[Design note]
Use a design note for commentary about why the game, framework, or publication
has been shaped in a particular way.
:::
