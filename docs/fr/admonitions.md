# Admonitions

Cette page sert de référence visuelle vivante pour les admonitions Markdown
prises en charge par le template. Elle est volontairement incluse à la fois dans
le site et dans la publication d'exemple afin que chaque renderer exerce la même
syntaxe source.

:::note[Note]
Utilisez une note pour apporter un contexte utile qui mérite l'attention sans
modifier la conduite à tenir du lecteur.
:::

:::tip[Conseil]
Utilisez un conseil pour une suggestion pratique, un raccourci ou une technique
qui peut faciliter le jeu ou la préparation.
:::

:::info[Information]
Utilisez une information lorsqu'un fait, une définition ou une clarification
doit être distingué du texte environnant.
:::

:::warning[Attention]
Utilisez un avertissement lorsque le lecteur doit avancer avec prudence parce
qu'un choix peut avoir des conséquences importantes.
:::

:::danger[Danger]
Utilisez danger pour le niveau d'alerte le plus fort : quelque chose risque de
casser, d'invalider ou de perturber fortement le résultat attendu.
:::

:::design[Note de design]
Utilisez une note de design pour expliquer pourquoi le jeu, le framework ou la
publication a été conçu d'une certaine manière.
:::
