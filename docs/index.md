# Resonance Site

This repository is the common publishing foundation for Resonance, Regard, and
the games built from them.

It provides a documentation-first website with:

- English and French editions;
- automatic language selection on the first visit;
- an explicit language switcher that remembers the reader's choice;
- a static build ready for GitHub Pages;
- a future extension point for downloadable PDF editions.
