# Site Resonance

Ce dépôt constitue le socle de publication commun à Resonance, Regard et aux
jeux qui en dérivent.

Il fournit un site centré sur la documentation avec :

- des éditions française et anglaise ;
- la sélection automatique de la langue lors de la première visite ;
- un sélecteur explicite qui mémorise le choix du lecteur ;
- une compilation statique prête pour GitHub Pages ;
- un point d'extension pour de futures éditions PDF téléchargeables.
